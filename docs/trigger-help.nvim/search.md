# / 搜索

## 基本

    /foo          向后搜索 foo
    n             下一个匹配
    N             上一个匹配
    *             光标下单词向后搜索
    #             光标下单词向前搜索

## 大小写

    /foo\c        忽略大小写
    /foo\C        严格大小写
    :set ic!      全局切换忽略大小写（<leader>rs）

## 模式

    /^foo         行首
    /foo$         行尾
    /^foo$        整行
    /foo\|bar     或
    /\<word\>     整词
    /a[bc]d       字符类（abd / acd）
    /a.c          . 任意字符
    /a.*c         任意数量

## 计数与跳转

    3/foo         第 3 个匹配
    /<C-r><C-w>   输入光标下单词
    /<C-r>/       输入上次搜索词
    /↑ / ↓        搜索历史

## 操作匹配

    gn            选中下一个匹配（配合 c/d/y）
    gN            选中上一个匹配
    cgnfoo        替换下一个匹配（. 可重复）

## 高亮

    :noh          清除高亮（或 <leader>rh）
    :set hls!     全局切换高亮
