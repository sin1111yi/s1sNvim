# ? 反向搜索

## 基本

    ?foo          向前（上方）搜索 foo
    n             下一个（向文件头方向）
    N             上一个（向文件尾方向）

注意：? 的 n/N 方向与 / **相反**——n 继续向前（上），N 向后（下）。

## 其他用法

    ?\c            忽略大小写（同 /）
    ?^foo          行首匹配
    ?foo$          行尾匹配
    ?\C            严格大小写
    ?↑ / ?↓        反向搜索历史

## 与 / 的区别

    /  →  向下搜索（光标之后）
    ?  →  向上搜索（光标之前）
    其余模式语法完全相同（见 / 搜索）
